## Название программы

«Random Quote Generator»

## Краткое описание программы

Приложение «Random Quote Generator» — это GUI‑приложение на Python, которое: * генерирует случайные цитаты из предопределённого списка; * отображает историю сгенерированных цитат; * позволяет фильтровать цитаты по автору и теме
